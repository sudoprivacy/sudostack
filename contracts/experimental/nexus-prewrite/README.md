# Experimental Nexus pre-write rejection

Byte-for-byte projection of nexus-vfs Write RPC schema and syscall-tested fixture.
Only the HTTP Agent Provider consumes this family, through Moss. It is not a Task,
Registry, end-user delegation, or general egress approval contract. Older kernels
omit the receipt and consumers preserve unknown. No sensitive content or matched
findings belong in this receipt. Its digest binds the original Write RPC bytes.

Run `node contracts/experimental/nexus-prewrite/generate.mjs --owner <nexus-vfs checkout> --check`
to validate the exact owner Git objects. Consumers additionally pin this Stack commit.
