- Sudocode v0.2.23 随固定 digest 的 Runtime，在 `RuntimeClass=gvisor`（handler `runsc`）Pod 中运行。
- 一键安装完成；重复执行相同安装包时，现有 Pod UID 全部保持不变。
- 浏览器实测密码登录到 SudoWork 主界面。
- HTTPS + WebUI 登录 + WebSocket + gVisor + 模拟模型回复 + 历史记录通过。
- 重启全部业务 Deployment 后，原会话能读取历史并完成新一轮对话。
- 实际执行加密冷备份；修改 Moss 文件和 PostgreSQL 测试数据后恢复，确认两者回到备份内容。
- Nexus vault 主密钥在重启和恢复前后 SHA256 不变；恢复后同一会话再次完成对话。
- 临时模型凭据和临时 Kubernetes 资源已删除。
- Chart lint、19 个 Kubernetes 资源严格 schema 校验通过；`latest` 镜像输入被 values schema 拒绝。
